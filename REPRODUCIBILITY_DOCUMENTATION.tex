\section{Purpose and scope}
This document describes the supporting data-and-code archive that accompanies the manuscript. The archive
is a self-contained, \textbf{offline, deterministic} reproduction: from a single command it regenerates
every reported number, table, and figure from frozen inputs, with \textbf{no network access, no API keys,
and no paid model calls}. The permanent citable version is the Zenodo archive at
\href{https://doi.org/10.5281/zenodo.21953934}{\code{10.5281/zenodo.21953934}} (code MIT-licensed); the
same tree is mirrored at \url{https://github.com/samirrc2/llm-credit-rating-specification-curve}.

A strict wall separates two phases. An \emph{offline analysis} reproduces every claim from frozen inputs
(documented here). A \emph{live capture} phase originally queried commercial model APIs and is retained
for transparency only (Section~8). Because commercial models change over time, capture is deliberately not
part of the reproducible core; the frozen model-response corpora it produced are shipped and hash-verified.
The confirmatory data are synthetic firm profiles benchmarked to an objective Altman Z$''$ reference; the
real-firm arm uses only publicly available SEC filings, anonymized and perturbed.

\section{Quick start}
\begin{quote}\code{pip install -r requirements.txt}\\ \code{bash reproduce.sh}\end{quote}
\textbf{Expected result:} the full analysis regenerates every \code{results/results\_*.json}; a second
independent run is byte-identical (the SHA-256 of each JSON result matches), and the run exits 0. Total
runtime is a few minutes on a standard laptop. No network access is required at any point.

\subsection{Provenance and integrity}
\code{manifest/} holds a SHA-256 manifest for every frozen stage: \code{MANIFEST\_INPUTS} (pre-registered
inputs), \code{MANIFEST\_RAW} (response corpus), \code{MANIFEST\_PANEL} (analysis panel),
\code{MANIFEST\_ANALYSIS}, \code{MANIFEST\_CAPITAL}, \code{MANIFEST\_MARKET}, \code{MANIFEST\_REALARM}, and
\code{MANIFEST\_FLAGSHIP} (flagship arm). \code{PREREGISTRATION.md} and \code{PREREGISTRATION\_AMENDMENTS.md}
freeze the design, so any silent change to an input or to the pre-registered plan is detectable before the
analysis runs. Post-hoc analyses (the flagship tier arm, the self-consistency curve, and the score
validation) are labelled as such in both the manuscript and this document.

\subsection{Data sources}
All confirmatory inputs are synthetic and self-contained: the 90-item battery is frozen and its Altman
Z$''$ benchmark is independently computable before any model is queried. The real-firm arm uses only
public SEC 10-K filings and XBRL company facts (keyless EDGAR; permanent URLs in
\code{ratings\_provenance.csv}); the disposable build cache is not shipped and is not needed to reproduce
any result. The original capture queried the OpenAI and Google APIs; those responses are frozen under
\code{data/raw/} and \code{capture/flagship\_runs/} and are the only trace of the live phase the
reproduction consumes.

\section{Reproduction and verification}
\code{reproduce.sh} performs, and exits non-zero if any stage fails:
\begin{enumerate}
\item \textbf{Integrity.} Each frozen stage carries a SHA-256 manifest (\code{manifest/}); the raw-corpus
freeze rejects any capture file above the pre-set error threshold (observed non-substantive rate 0.08\%,
7 of 8{,}640 confirmatory cells, dropped listwise).
\item \textbf{Regeneration.} The full analysis (Section~5.2) runs from the frozen inputs only.
\item \textbf{Byte-identical re-run.} Re-running \code{reproduce.sh} regenerates every
\code{results/results\_*.json} byte-for-byte (verified); the results of record are the committed JSON files.
\end{enumerate}
\textbf{Determinism.} All stochastic steps use fixed seeds (analysis seed 42; issuer-clustered bootstraps
use fixed-seed resamples), so confidence intervals are exactly reproducible. \emph{Note:} Parquet
serialization is not byte-deterministic, so a rebuilt \code{panel.parquet} may hash differently while
containing row-identical data; the confirmatory analysis reads the released frozen panel, so every
reported number reproduces exactly.

\textbf{Environment.} Pinned analysis environment: \code{numpy==2.2.6}, \code{pandas==2.2.3},
\code{pyarrow==24.0.0}, \code{statsmodels==0.14.6}, \code{scipy==1.15.3}, \code{patsy==1.0.2}, on
Python~3.10 (exact pins in \code{requirements.txt}). Figures are optional and need \code{matplotlib},
which is not part of the pinned analysis dependencies.

\section{Live data collection (not part of the reproduction)}
\code{capture/} documents how the model-response corpora were originally collected: \code{collect.py}
drives the main confirmatory grid; \code{run\_arm.py} and \code{realarm\_collect.py} run the real-firm arm;
\code{run\_flagship.py} runs the flagship model-tier arm; \code{freeze\_flagship.py} writes its SHA-256
manifest; \code{fingerprint\_pilot.py} runs the decontamination gate; \code{list\_models.py} enumerates
served models. This phase requires internet access and OpenAI/Google API keys, incurs cost, and is
intentionally excluded from the reproducible core. API keys are never distributed (\code{.gitignore}
blocks \code{keys.env.txt} and any \code{API~Keys/} folder); all reported results derive only from the
frozen corpora.
